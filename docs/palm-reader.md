# 看手相师（palm_reader）

> 掌纹自我觉察 · 娱乐向非命运预言 · 需在相机里**手动选「看手相师」**

## 流程

```text
选看手相师 → 拍照/相册 → 生日收集（可跳过）→ 分析中（思考步骤）→ 洞察页（Chance 版式）→ 追问
```

## Chance 洞察页结构

1. 「与手相师一起看见 ›」+ 诗意称号 + 开场叙事  
2. **摘要特质卡**：手型 / 核心纹路 / 独特标记  
3. **视觉卡**：掌心图 + 虚线叠加 +「线名 / 年龄高光」标注  
4. **主线折叠卡**：感情线 → 智慧线 → 生命线 → 事业线（高光 + 形态→含义）  
5. **性格光谱**滑条  
6. **金句**卡  
7. **匹配度**邀请卡  
8. 追问芯片

## 关键接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/v1/analyze` | `agent_override=palm_reader`，可选 `birthday=YYYY-MM-DD` |
| POST | `/v1/followup` | 返回结构化 `structured_answer` |

`palm_reading.summary_traits` 与 `palm_lines` 为 Chance 版式核心字段。
